# AI and IT Skill Roadmap

## Purpose

This roadmap was created from my Job Skills Analyzer project.

The goal is to identify the true transferable skills that appear across AI, IT, data, cybersecurity, cloud, and software roles.

## Main Finding

The strongest repeated skills from the job market sample were:

1. Python
2. Git/GitHub
3. Cybersecurity
4. Observability/logging
5. APIs
6. Cloud
7. Docker
8. SQL
9. Documentation
10. Communication
11. LLMs
12. Linux

## My True Skill Stack

### 1. Python

Python is my main technical foundation. I will use it for automation, data analysis, AI tools, APIs, scripting, and cybersecurity practice.

### 2. Git and GitHub

Git and GitHub are used to track my work and prove my skills publicly through projects, commits, README files, and version history.

### 3. Cybersecurity Basics

Cybersecurity is important because AI and software systems must be safe. I need to understand authentication, secrets, permissions, logging, secure coding, and data protection.

### 4. APIs

APIs are how real systems connect. I need APIs for AI tools, web apps, automation, cloud services, and backend development.

### 5. SQL

SQL is important for working with databases, reports, dashboards, backend systems, and AI projects that depend on structured data.

### 6. Linux and Command Line

Linux and command-line skills are important for servers, cloud work, Docker, cybersecurity labs, and deployment.

### 7. Cloud Basics

Cloud skills are important because many real-world systems run on AWS, Azure, or Google Cloud. I will focus on one cloud platform first.

### 8. Docker

Docker helps package and run applications in a reliable way. This is important for real-world deployment and team development.

### 9. Observability and Logging

Observability means being able to understand what a system is doing. Logging and monitoring help with debugging, security, and reliability.

### 10. Documentation and Communication

Documentation and communication are essential because employers need people who can explain technical work clearly, write instructions, and communicate with users or teams.

### 11. LLMs, RAG, and AI Agents

This is my AI specialization layer. After strengthening my foundation, I will build AI projects using LLMs, retrieval-augmented generation, tool calling, and agent workflows.

### 12. Machine Learning Basics

Machine learning basics will help me understand models, training, evaluation, data preparation, and AI limitations.
